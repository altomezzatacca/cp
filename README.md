# cp
Everything competitive programming related.

This repo contains my solutions from all the competitive programming websites I'm registered on, as well as a collection of useful algorithms.

Everything is written in **C++**. Currently, there are solutions from:
- training.olinfo.it
- cses.fi
- codeforces.com
- atcoder.jp
- open.kattis.com

The source folders contains a "bits" folder, that helps compiling faster by using pre-compiled <bits/stdc++.h> and <cassert> headers made by the command "g++ -c bits/stdc++.h". Therefore, the most recent files use "bits/stdc++.h" instead of <bits/stdc++.h>. The binary file is not included in the repo because of its size.
